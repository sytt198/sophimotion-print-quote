# SophiMotion 3D 打印报价分析系统

日期：2026-10-16

## 已确认需求

- 交付 HTML 网页应用，目标仓库为 https://github.com/bobwu0214/sytt198 。
- 第一版覆盖 FDM 熔丝与光固化。
- 上传 STL、STEP，使用 Three.js 预览与分析模型。
- 分析尺寸、体积、表面积、材料和重量，生成整单 Excel 与 PDF 报价单。
- 遵循 SophiMotion 品牌：随技能提供的 SVG Logo、#0057FF、Arial 与系统中文字体、克制布局。

## 推荐实现

采用静态网页应用，模型在浏览器本地解析。HTML 配合独立 JavaScript、样式、CAD/WASM 与字体资产，打包后可静态托管。相比把所有内容塞进单个 HTML，此方式更便于维护 STEP 解析和中文 PDF 字体；不强制引入服务器。

Three.js 负责三维显示，STL 使用网格加载器，STEP 使用浏览器 CAD/WASM 解析器转换为可显示网格。STEP 优先保留 CAD 实体体积；仅有网格体积时明确标注为网格估算。不将三角化后的数值冒充精确 CAD 测量。

## 页面与流程

桌面采用左侧零件清单、中间模型预览、右侧工艺与报价设置，下方整单汇总。窄屏纵向排列。提供浅色和深色主题；第一版中文界面。

1. 上传一个或多个模型，显示逐文件解析进度与错误。
2. 确认单位与缩放；STL 不带可靠单位，默认毫米并可调整。
3. 查看尺寸、体积、表面积及网格问题；开放网格不能直接生成可靠实体重量，标记待修复或人工输入体积。
4. 逐零件选择 FDM 或光固化、材料、数量和工艺参数。
5. 编辑成本规则，查看每件和整单价格。
6. 填写客户、报价编号、有效期、交期、备注，导出 Excel 和 PDF。

预览提供旋转、缩放、适配模型、标准视角、线框、实体显示；清单支持切换、移除零件并释放图形资源。

## 材料与重量

模型几何不能可靠推断实际打印材料；材料由用户选择。材料库中的密度和价格均可修改，示例值明确标为参考参数，正式报价前需确认。

FDM 材料库覆盖 PLA、PETG、ABS、ASA、TPU、PA；光固化覆盖标准、韧性、耐高温和可水洗树脂。密度按具体材料/供应商录入，不按材料大类冒充唯一精确值。

- 实体重量 g = 模型体积 cm³ × 材料密度 g/cm³。
- FDM 快速估算：外壳体积近似为 min(实体体积, 表面积 × 等效壳厚)；打印体积 = 外壳体积 + 剩余内部体积 × 填充率。表面积需换算到 cm²，厚度换算到 cm。该公式仅为报价近似，不能替代切片。
- FDM 消耗重量 = (打印体积 + 支撑体积) × 密度 × (1 + 损耗率)。可人工输入或覆盖切片耗材重量和时长，覆盖值优先并标明来源。
- 光固化实心模式使用实体体积；空心模式允许输入实际壳体积或采用带明确提示的壳体近似。消耗体积 = (零件打印体积 + 支撑体积) × (1 + 损耗率)，重量 = 消耗体积 × 树脂密度。
- 光固化估时可按人工确认打印高度、层高、每层曝光和抬升耗时计算参考值；摆放和设备会影响结果，允许覆盖。

未提供支撑量、时长或费率时保留缺失提示，不用零值伪装完整报价。允许保存草稿，但未补齐关键值的导出标注“估算/待确认”。

## 费用规则

所有金额默认人民币。材料单价统一按元/kg 计算，光固化额外显示 ml 消耗便于核对。

- 材料费 = 消耗重量 g / 1000 × 元/kg。
- 加工费 = 确认的打印小时数 × 设备小时费率。
- 单件基础成本 = 材料费 + 加工费 + 单件后处理费。
- 行成本 = 单件基础成本 × 数量 + 该行设置费。
- 未税售价 = 成本 × (1 + 成本加价率)，字段明确称为成本加价率，避免与毛利率混淆。
- 整单未税金额 = 各行未税售价之和 + 运费 - 优惠。
- 税额 = 整单未税金额 × 税率；含税总额 = 未税金额 + 税额。

支持最低收费，并明确展示补差。逐行金额按分取整后汇总，界面与导出共用同一份结果，避免金额不一致。多件共板打印的时长由用户填写，不能简单将同板时长重复按件收费；第一版提供整行总机时覆盖。

## Excel 与 PDF

Excel 提供报价汇总、零件明细、成本明细、参数与估算依据四个工作表；不使用 CSV 假冒 XLSX。

PDF 使用中文字体和品牌 SVG/适当转换后的 Logo，包含客户信息、报价编号、零件与工艺、材料、数量、价格、税额、总额、有效期、备注和估算说明。支持多页表格与重复表头。对客 PDF 默认隐藏内部成本，Excel 保留成本明细。导出前显示可预览的报价内容。

## 验证与边界

- 用已知尺寸立方体核对体积、表面积、单位和实体重量。
- 验证开放网格、空文件、解析失败、重复上传、移除模型和大文件错误反馈。
- 检查 FDM 和树脂计算、手动覆盖、数量、整行机时、最低收费、税费及舍入。
- 检查 XLSX 真实文件格式、明细与总额一致性；检查 PDF 中文、分页和品牌资产。
- 检查桌面与手机布局、键盘焦点、主题切换、无 WebGL 提示。

不承诺自动识别材料、自动切片或由 STL 自动还原原始 CAD 实体。第一版为可配置报价估算工具；接入实际切片引擎可作为后续独立功能。
