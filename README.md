# sytt198

## SophiMotion 3D 打印报价工作台

支持 FDM 熔丝和光固化的静态网页报价应用。上传的模型只在浏览器内处理，无需账号或模型上传服务器。

### 功能

- STL / STEP / STP 上传，Three.js 三维预览、旋转、缩放、线框、标准视角。
- 尺寸、网格体积、表面积、闭合与异常边检查；STL 支持毫米/厘米/英寸/米转换，STEP 统一毫米。
- FDM：材料密度、单价、壳厚、填充率、支撑、损耗、切片重量覆盖。
- 光固化：树脂材料、实心/空心、壳体积、支撑体积、损耗及参考机时计算。
- 多零件数量、整行机时、后处理、设置费、成本加价、最低收费、运费、优惠与税费。
- Excel 四张工作表：报价汇总、零件明细、成本明细、参数与估算依据。
- 中文 PDF 预览与下载，对客 PDF 隐藏内部成本，长报价分页。
- 浅色/深色/跟随系统，手机布局，SophiMotion 品牌 SVG。

### 本地运行

需要 Node.js 22.14 或更高版本：

```sh
npm ci
npm run dev
```

打开终端提示的本地网址。生产构建与预览：

```sh
npm test
npm run build
npm run preview
```

`dist/` 是完整静态网页，包含模型解析器 WASM，无需外部 CDN。请通过 HTTP 静态服务打开；直接双击 HTML 的 `file://` 方式不能加载模块和 Worker。部署时上传整个 `dist/`，不能只上传一个 HTML。

仓库的 `web/` 目录是已构建版本，可直接放入静态网站服务。`.github/workflows/check.yml` 仅构建与测试，并提供构建产物；不会自动启用 GitHub Pages 或发布网站。

### 报价依据与限制

材料不能由几何文件可靠自动识别，需人工选择。材料库的密度、价格与费率是可编辑参考值，必须按实际品牌/供应商核对。未填写的支撑和机时保持“待确认”；无支撑应明确填写 0。首次上传真实模型会自动移除演示零件，避免示例混入报价。

FDM 壳体体积近似为 `min(实体体积, 表面积 × 等效壳厚)`，内部体积按填充率计算；树脂实心使用实体体积，空心可填实际壳体积。耗材体积增加支撑后计入损耗，再乘密度计算重量。切片重量覆盖优先，且不再重复添加支撑或损耗。

价格按成本加价率计算（不是毛利率），整行最低收费参与补差。整行总机时优先且不再乘数量，适用于共板打印。材料费按整行原始耗材乘数量后取分，避免小件批量单低估；界面、Excel 和 PDF 共用计算结果，行金额按分舍入后汇总。

所有模型体积来自三角化网格，为估算；STEP 未进行精确 CAD 实体体积计算。闭合检查不能排除自相交、重叠实体或所有不可制造情况。多实体重叠会重复累计体积。同一网格含多个朝向混合的独立壳体时（包括部分封闭空腔模型），系统不自动使用可能抵消的体积，需填写确认体积或切片重量。耗材和机时以最终切片结果为准，参考机时不替代实际切片。

限制：单文件 50 MB、每文件 300,000 三角形、每单 30 个模型；STEP 解析 90 秒超时。刷新会清空模型与本单参数，仅外观选择持久保存。PDF 使用高清图像保留中文，文字不可搜索。

### 验证

`npm test` 覆盖已知立方体几何、缩放、开放网格、FDM 与树脂、切片覆盖、整行机时、最低收费、税费和非法输入。已用 Chrome 实测桌面/手机、STL/STEP 上传、主题、材料切换、模型移除、XLSX 读取和 PDF 下载。STEP 验证使用 OCCT 项目官方立方体样例。
